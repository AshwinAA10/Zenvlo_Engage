# Zenvlo Engage — Branding Assets

This directory contains the branding assets for Zenvlo Engage:

1. **`logo.png`**:
   - Primary expanded logo displayed in the expanded sidebar navigation, authentication screen, and external headers.
   - Recommended dimensions: 400x100 px with transparent background.
   - Visual identity: Pitch-Black Obsidian + Emerald accent (`#10B981`).

2. **`favicon.png`**:
   - Square icon mark displayed in the browser tab and the collapsed sidebar navigation state.
   - Recommended dimensions: 128x128 px or 64x64 px.
   - Visual identity: Obsidian surface with Emerald lighting mark.
